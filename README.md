## 写作纪律

1. 每个数字有出处 —— 报告原文、公告、年报 PDF、监管文件优先
2. 区分三种可信度 —— 「报告原文确认」「媒体转述」「分析师判断」
3. 框架带边界 —— 每个框架都写清什么时候别用
4. 结论可被推翻 —— 主结论条件式，红队以书面判决落地

## 技术栈

Astro + Tailwind CSS，静态输出，GitHub Pages 部署。

- `npm install && npm run build` —— 构建到 `dist/`
- `python3 tools/privacy_scan.py dist/` —— 隐私扫描，命中红线则拒绝部署

**隐私约定**：本站不挂任何第三方追踪脚本。当前雇主名统一写作「头部云厂商」，与简历站保持一致 —— 避免两站交叉时被公开关联。
